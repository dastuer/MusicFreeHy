# 调试数据源（本地 WebDAV）

开发调试用的一套固定 WebDAV 备份数据，方便随时把应用恢复到已知的测试状态。

## 连接信息

| 项 | 值 |
|---|---|
| 服务器地址 | `http://127.0.0.1:1900` |
| 账号 | `admin` |
| 密码 | `331203` |
| 备份文件路径 | `/MusicFree/TestDatat.json` |

> 1900 端口的 WebDAV 服务跑在本机（电脑）上。真机调试时 `127.0.0.1` 指向手机自身，
> 需换成电脑的局域网 IP（如 `http://192.168.x.x:1900`），并保证手机与电脑同一网络。

## 使用方法

1. 打开「设置 → 备份与恢复 → WebDAV 设置」，填入上面的服务器地址、账号、密码和文件路径；
2. 点「测试」确认连接成功；
3. 回到「备份与恢复」页，点「从 WebDAV 恢复 → 下载」即可。
